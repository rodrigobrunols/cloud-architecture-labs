#### 2. `LICENSE`
Licença MIT padrão com o ano atual.

#### 3. `README.md` (Raiz)
- Título: ☁️ Cloud Architecture Labs & Weekly Insights
- Badges: AWS Architecture, Terraform IaC, LinkedIn Series, MIT License.
- Descrição: Repositório com implementações práticas de Infraestrutura como Código (Terraform) que acompanham os posts semanais sobre arquitetura e computação em nuvem no LinkedIn.
- Tabela de Labs: Linha para #01 - Roteamento na Edge com CloudFront Behaviors com links relativos.
- Guia de execução rápida: Comandos de git clone e terraform init.

#### 4. `01-cloudfront-behaviors/README.md`
- Título: Lab 01: Roteamento Inteligente na Edge com CloudFront Behaviors
- Contexto & Problema: Por que desacoplar containers (lógica de negócio) de assets estáticos (S3 + CDN).
- Diagrama de Arquitetura em Mermaid: Fluxo do usuário acessando https://mystore.com e o CloudFront distribuindo para S3 (/images/* e SPA *) e ALB (/api/*).
- Tabela de Behaviors: Path Pattern, Destino, Política de Cache e Métodos HTTP permitidos.
- Instruções passo a passo de deploy com Terraform.

#### 5. `01-cloudfront-behaviors/main.tf`
Implementação Terraform limpa e moderna utilizando:
- AWS Managed Cache Policies (Managed-CachingOptimized e Managed-CachingDisabled).
- AWS Managed Origin Request Policy (Managed-AllViewerExceptHostHeader).
- Buckets S3 com CloudFront Origin Access Control (OAC) (bloqueando acesso público direto ao bucket).
- Bucket Policies concedendo leitura exclusiva ao CloudFront via OAC.
- Origem ALB customizada com HTTPS.
- ordered_cache_behavior para /images/* (S3, cache longo, compressão Brotli/Gzip).
- ordered_cache_behavior para /api/* (ALB, cache desativado, métodos GET, POST, PUT, DELETE, PATCH).
- default_cache_behavior para o frontend SPA (* com fallback para index.html via Custom Error Responses 403/404).

#### 6. `01-cloudfront-behaviors/variables.tf`, `outputs.tf` e `terraform.tfvars.example`
- Variáveis parametrizadas: aws_region, environment, project_name, api_alb_dns_name.
- Outputs: cloudfront_distribution_id, cloudfront_domain_name, frontend_s3_bucket, assets_s3_bucket.

#### 7. `01-cloudfront-behaviors/generate_carousel.py`
Script Python completo (usando reportlab ou geração vetorial PDF nativa) que cria o arquivo carrossel_cloudfront_behaviors.pdf com:
- 5 slides no formato quadrado 1080x1080px (Dark/Tech Theme, cores AWS #FF9900 e #38BDF8).
- Tipografia e cartões elegantes de arquitetura (Terminal, Containers vs S3, Rotas, Ordem de Precedência).
- Texto em português com acentuação impecável (codificação WinAnsi / CP1252 para PDF).
